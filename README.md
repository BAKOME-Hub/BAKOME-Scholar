## 📖 Description

**EN** — BAKOME-Scholar v5.0 is a production-ready universal scientific search engine written in pure Rust. It queries 6 major academic sources simultaneously (Wikipedia, arXiv, PubMed, CrossRef, Semantic Scholar, Google Scholar), features a mini neural network for fraud detection with 50+ patterns, supports 15 languages, and provides a live animated web dashboard with real-time statistics, floating particles, and interactive search.

**ES** — BAKOME-Scholar v5.0 es un motor de búsqueda científica universal listo para producción escrito en Rust puro. Consulta 6 fuentes académicas principales simultáneamente (Wikipedia, arXiv, PubMed, CrossRef, Semantic Scholar, Google Scholar), cuenta con una mini red neuronal para detección de fraude con más de 50 patrones, soporta 15 idiomas y proporciona un panel web animado en vivo con estadísticas en tiempo real.

**ZH** — BAKOME-Scholar v5.0 是一个用纯Rust编写的生产级通用科学搜索引擎。它同时查询6个主要学术来源（Wikipedia、arXiv、PubMed、CrossRef、Semantic Scholar、Google Scholar），具有50多个模式的迷你神经网络欺诈检测功能，支持15种语言，并提供带有实时统计数据的动态Web仪表板。

## ⚡ Features

| Module | Description |
|--------|-------------|
| 🔍 **6 Academic Sources** | Wikipedia, arXiv, PubMed, CrossRef, Semantic Scholar, Google Scholar |
| 🧠 **Neural Fraud Detection** | Mini neural network with 50+ scam/phishing/pseudoscience patterns |
| 🌐 **15 Languages** | EN, FR, ES, ZH, AR, RU, PT, DE, JA, KO, IT, HI, NL, SV, PL |
| 💻 **Live Animated Dashboard** | Floating particles, gradient animations, live ticker, real-time stats |
| 📡 **REST API** | `/api/search?q=`, `/api/stats` endpoints |
| ⚠️ **Fraud Alerts** | Pulsing red alerts for suspicious content |
| 💡 **Smart Suggestions** | Related queries, sentiment analysis, neural insights |
| 🦀 **Pure Rust** | Memory safe, blazing fast, zero-cost abstractions |
| 📱 **Responsive Design** | Works on mobile, tablet, and desktop |

## ⚙️ Quick Install

```bash
git clone https://github.com/BAKOME-Hub/BAKOME-Scholar.git
cd BAKOME-Scholar
cargo build --release
cargo run --release
```

Open http://localhost:3002 in your browser.
